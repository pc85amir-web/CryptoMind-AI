# CryptoMind AI

دستیار هوشمند تحلیل بازار ارزهای دیجیتال

## امکانات نسخه اولیه

- دریافت اطلاعات عمومی نوبیتکس
- بررسی بازارهای رمزارزی
- تحلیل تکنیکال
- محاسبه RSI و EMA و MACD
- شناسایی فرصت های صعودی و نزولی
- بررسی حمایت و مقاومت
- نمایش نمودار کندل استیک
- مدیریت سرمایه اولیه

## تکنولوژی ها

- Python
- Streamlit
- Pandas
- NumPy
- Plotly
- Nobitex Public API

## اجرا

ابتدا کتابخانه های موردنیاز را نصب کنید:

pip install -r requirements.txt

سپس برنامه را اجرا کنید:

streamlit run app.py
